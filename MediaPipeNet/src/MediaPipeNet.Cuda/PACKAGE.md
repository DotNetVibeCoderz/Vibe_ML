# Gravicode.MediaPipeNet.Cuda

All vision tasks plus the **CUDA** ONNX Runtime for NVIDIA GPUs (Windows/Linux, CUDA 12 + cuDNN 9). Reference this *instead of* `Gravicode.MediaPipeNet`. `ExecutionProvider.Auto` picks CUDA first and falls back to CPU.

---
**MediaPipe.NET** — a native .NET 10 port of Google MediaPipe's vision tasks on ONNX Runtime.
