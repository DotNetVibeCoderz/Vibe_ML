# Gravicode.MediaPipeNet.Core

Core primitives shared by every MediaPipe.NET package: `Timestamp`, `NormalizedLandmark`, `Landmark`, `Detection`, `Category`, `RectF`, `NormalizedRect`, telemetry (`System.Diagnostics.Metrics` meter `Gravicode.MediaPipeNet`) and JSON settings.
