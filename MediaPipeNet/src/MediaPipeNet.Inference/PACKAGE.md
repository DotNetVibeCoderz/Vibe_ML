# Gravicode.MediaPipeNet.Inference

ONNX Runtime wrapper with preallocated, pooled I/O buffers (zero allocations per inference, thread-safe), automatic execution-provider selection (CUDA → DirectML → CoreML → CPU) and model management: `ModelCatalog`, `ModelStore`, checksum verification, cache, NuGet/HTTP/embedded providers.

---
**MediaPipe.NET** — a native .NET 10 port of Google MediaPipe's vision tasks on ONNX Runtime.
