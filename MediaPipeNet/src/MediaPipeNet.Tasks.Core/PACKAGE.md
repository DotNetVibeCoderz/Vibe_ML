# Gravicode.MediaPipeNet.Tasks.Core

Foundations shared by every MediaPipe.NET task package (vision, audio, text): `BaseOptions` (where models
come from, execution provider, logging), `ModelLoader` and classification post-processing (`ClassifierOptions`).
You normally get it through `Gravicode.MediaPipeNet.Tasks.Vision`, `.Tasks.Audio` or `.Tasks.Text`.
