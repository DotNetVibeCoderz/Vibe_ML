Installed

Pull a small model and check it works — this one is about 100 MB:

localgen pull huggingface:bartowski/SmolLM2-135M-Instruct-GGUF
localgen run smollm2-135m-instruct:q4_k_m "Say hello"

Or open LocalGen Admin Control from Applications, which does the same from the Models and Playground screens and can start the API service.

Models are stored in ~/.localgen and are not removed when LocalGen is uninstalled.
