LocalGen

A local AI inference engine. It runs open language models on this machine and serves them through an API that speaks OpenAI's protocol, so existing clients work against it unchanged.

This installs three things:

  • LocalGen Admin Control in Applications — models, engines, playground and monitoring
  • localgen on the command line
  • localgen-server, the API service, started on demand

No model is downloaded during installation. Inference itself never needs the network.
