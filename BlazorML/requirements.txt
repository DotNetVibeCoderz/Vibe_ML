nama:
Blazor ML Studio (BlazorML)

deskripsi:
Platform drag‑and‑drop berbasis web untuk membuat, melatih, dan menerapkan model ML tanpa banyak coding (seperti Azure ML Studio Classic). Fitur utamanya berfokus pada kemudahan eksperimen, integrasi data, dan deployment cepat. Fiturnya:

- Drag‑and‑Drop Interface  
  Membuat alur kerja ML dengan modul visual tanpa perlu menulis kode. Terdapat actions yang memanfaatkan LLM juga seperti (formatting, cleansing, sentiment detection, custom prompt)

- Data Import & Transformation 
  Mendukung input dari Azure Blob, S3, MinIO, SQL Database, CSV, dan web services. Termasuk modul untuk cleaning, normalization, dan feature selection.

- Prebuilt Algorithms  
  Library algoritma ML klasik: regression, classification, clustering, anomaly detection, recommendation. Untuk masing-masing task terdapat pilihan algoritma yang berbeda.

- Experimentation Environment  
  Menyusun eksperimen, menjalankan training, dan membandingkan hasil model secara visual.

- Evaluation & Scoring  
  Modul untuk ROC curve, confusion matrix, dan evaluasi performa model.

- Web Service Deployment  
  Model dapat langsung dipublikasikan sebagai REST API endpoint dengan MinAPI dan swagger. Secure by ApiKey

- Reproducibility & Versioning  
  Menyimpan eksperimen dan versi model untuk audit dan pengulangan.

- Integration with R, Python, JS dan C# script  
  Mendukung script custom untuk memperluas fungsionalitas.

- Marketplace & Sample Experiments  
  Template eksperimen beserta dataset siap pakai untuk rekomendasi film, prediksi harga, sentiment analysis, dll.

- Automated ML  
  AutoML untuk classification, regression, vision, NLP tanpa coding mendalam.
