# SciPy - Daftar Fitur Lengkap

## Tentang SciPy

SciPy adalah salah satu library scientific computing terbesar di Python. Dibangun di atas NumPy dan menyediakan berbagai algoritma untuk matematika, statistik, optimisasi, signal processing, aljabar linear, komputasi ilmiah, dan engineering.

---

# 1. scipy.linalg

Aljabar linear tingkat lanjut.

Fitur:

- Matrix inversion
- Eigenvalue decomposition
- Eigenvector computation
- LU decomposition
- QR decomposition
- Singular Value Decomposition (SVD)
- Cholesky decomposition
- Linear equation solver
- Matrix functions

---

# 2. scipy.optimize

Optimisasi dan pencarian solusi numerik.

Fitur:

- Function minimization
- Function maximization
- Nonlinear optimization
- Constrained optimization
- Global optimization
- Curve fitting
- Least squares
- Root finding

Algoritma populer:

- BFGS
- L-BFGS-B
- Nelder-Mead
- Powell
- SLSQP
- COBYLA
- Differential Evolution
- Simulated Annealing
