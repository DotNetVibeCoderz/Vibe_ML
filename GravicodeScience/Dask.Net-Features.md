# Dask.Net - Distributed Parallel Computing Framework for .NET

## Visi Produk

> Run .NET workloads from a single process to a distributed cluster.

Misi utama:

- Alternative .NET-native untuk Dask
- Lebih ringan dari Apache Spark
- Integrasi penuh dengan .NET 10
- Mendukung cloud-native deployment
- Mendukung AI, GIS, dan Data Engineering

# Diferensiasi

Dask.Net diposisikan sebagai gabungan kekuatan Dask, Polars, Spark, dan Orleans dengan pengalaman developer yang sepenuhnya native .NET 10 dan terintegrasi erat dengan Azure, Aspire, AI, serta ekosistem geospasial modern.
